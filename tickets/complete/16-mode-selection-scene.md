# Ticket 16: Mode Selection Scene

## Summary
Allow players to select a preset or custom board and start a playable game.

## Details
Connect the menu and mode selection to the existing game factory, rules and
board presentation. Validate custom dimensions and mine count before starting.

## Definition of Done
- [x] Easy, medium, hard and custom games can be selected.
- [x] Invalid custom input is explained without closing the dialog.
- [x] The selected configuration starts a playable board.
- [x] Board clicks and flag toggles update the underlying game.
- [x] Focused tests and ticket summary are provided.
