# Ticket 17: Game Controls & Information Display

## Summary
Provide game controls and live game information on the board screen.

## Details
Allow a player to return to mode selection, restart the current configuration,
and open settings. Show remaining mines, elapsed time and game status.

## Definition of Done
- [x] New game, restart and settings navigation work.
- [x] Mine count and game status update after moves.
- [x] Elapsed time updates during a game and stops on win or loss.
- [x] Focused tests and ticket summary are provided.
