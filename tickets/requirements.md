### Requirements

## Overview
A minesweeper game, based on the classic. This should be a GUI based game, with several modes including a custom size.

## MVP
- Console version to prove logic works.
- This should include the following:
  - Multiple modes
    - Easy, Medium, Difficult, Custom
      - Easy (10x10 w/ 1 bomb)
      - Medium (20x20 w/ 2 bomb)
      - Hard (30x30 w/ 3 bomb)
      - Custom 
- There should be unit tests covering this
- There is no language restrictions, use the most appropriate technologies for the task.
- An observer mode, that allows you to watch an AI play the game.

## Final Version
- GUI
- All modes present
- Proximity numbers from the tile selected
